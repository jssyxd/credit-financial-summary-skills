# 反幻觉核查清单（Anti-Hallucination Checklist）

用于：把自己（或他人/其他 AI）的财务分析/简表与**源证据**逐条对质，产出可裁定的差异清单。

## 0. 证据底座（先建立）
- [ ] 每一年度的 `auditYYYY.json`：BS 配平、IS/CF 链式恒等全部 OK；
- [ ] 跨年连续性：`后年期初 == 上年期末`，差异逐条归因（命名变体 / 口径拆分）；
- [ ] 若存在文本层同期报表（如银行近一期简式表）：其“年初余额”与上一审计年末逐科目一致；
- [ ] 附注 OCR（notes*.json）：确认披露粒度（极简版 → 前五名/账龄分段/坏账/折旧拆分不可写）。

## 2. 反幻觉必查模式（实战高频）
1. **整行/整列错位**：科目 A 的某年值=科目 B 的同列值（例：应付票据2023 填入应付账款数；预收 2026.6 填成应付职工薪酬）。识别法：跨年连续性 + 该行是否“整体右移一年”。
2. **虚构精度**：折旧摊销/前五名/坏账率等附注未披露数字（例：EBITDA 隐含折旧 1,200 万/年与净值变动矛盾）。识别法：净值变动+购置现金反推折旧，量级不符即虚构。
3. **无源具体化**：把推断写成定论（“资本公积转增”“浙江、广西基地注资 9.3 亿”“未动用授信”“资金池机制”）。识别法：附注/征信未披露 → 只能写“主要系/结合…判断/以征信为准”或交人工核验。
4. **口径不自洽**：同一指标不同年份用期末 vs 平均分母（存货/应收/总资产周转）。识别法：统一口径重算。
5. **与文本锚点矛盾**：叙述方向与源相反（例：预收“已结转清零”而实际较年初翻倍）。识别法：与近一期文本层报表逐项对账。

## 3. 输出
- 核查报告 md：`结论先行（数据/语气分别谁优）→ 对方问题表(表述/事实/裁定) → 我方自检表(含残留待人工确认) → 使用建议(替换范围)`；
- 每一条对方错误给出“正确值 + 证据来源”；数值替换**留痕**，不静默改对。

## 4. 我方自检（交稿前）
- [ ] 每个数字可回到 JSON 的某科目+年份；
- [ ] 推断句含限定词（主要系/结合…判断/以…为准）；无源数字已删除或标注；
- [ ] 口径注齐全（EBITDA 未含折旧、半年*年化、利息保障半年不列、短期债务定义）；
- [ ] 与源重算的 306 格复算 0 差异；
- [ ] 列出“残留待人工确认”清单（授信额度、资金池协议、征信、未复核页等）。
