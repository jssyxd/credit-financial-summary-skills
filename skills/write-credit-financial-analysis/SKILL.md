# Skill: write-credit-financial-analysis

按《授信调查报告》体例撰写**财务分析正文 + 财务指标分析表**，输出可直接并入报告的 docx 与 xlsx；内置“软化负面话术”“±30% 重点科目展开”“与他人版本反幻觉互查”方法。

## 触发场景
- 用户要求“写一份 XX（单体/合并）财务分析”“参照授信调查报告资产负债重点项目分析段”“做一个财务指标分析表”“避免负面评价、话术软化为尚可之类”；
- 已有多年度简表数值（xlsx/JSON）或刚完成 build-financial-summary-xlsx；
- 需要与另一份（其他 AI/同事）做的分析/简表互相核查谁优谁劣。

## 前置
- `pip install openpyxl python-docx`；
- 证据：`auditYYYY.json`（含期初档）、近一期文本层报表、`notes*.json`（附注 OCR，判披露粒度）。

## 步骤

### 1. 搭好证据与口径（防幻觉，先于写作）
- 运行 `extract-financial-statements/scripts/validate_extraction.py` 确认配平+连续性；
- OCR 附注 2~3 页判断披露粒度：**极简版（各科目仅总额）→ 不得写前五名/账龄分段/坏账率/折旧拆分**；
- 若近一期有文本层报表，把其“年初”列作为上一审计年末的锚点，**叙述方向必须与锚点一致**（如预收款项是升是降，用锚点定死）。

### 2. 正文结构（对应报告(二)~(四)）
1. 总体概况（定位/口径分工/规模趋势）；
2. 资产负债重点科目：货币资金(含交易性金融资产)、应收账款与应收票据、预付账款、其他应收款、存货、长期股权投资、固定资产与在建工程、负债结构与短期借款、应付账款与预收款项、其他应付款——科目顺序与标题可随行内模板调整；
3. 应收应付及存货专项分析（余额/变动/占比表 + 总体判断）；
4. 损益及盈利情况分析（收入成本毛利率、费用、其他损益、净利与留存解释）；
5. 现金流情况分析（经营/投资/筹资 + 现金回收率）；
6. 综合评价（授信视角，正面结论）。

**写法规则**
- 每个科目：`金额序列(三年一期) → 大额变动(>±30%重点展开) → 原因(有源/限定词) → 对冲事实 → 温和收尾`；
- 近三年一期金额必须与简表逐字一致（从 JSON/简表读取，勿凭记忆）；
- 参考报告(四)段落风：`截至20XX年末，X科目XX万元，占总资产X%。变动…原因…。近一期…。`

### 3. 话术软化对照（避免负面评价）
| 不要 | 改法 |
| --- | --- |
| 骤降/暴增/断崖/锐减 | 有序收窄 / 大幅下降(上升) + 归因与对冲事实 |
| 账面现金不足/备付风险 | 资金投向实体与偿债 + 经营现金流持续覆盖 + 集团统筹 + “保障尚可” |
| 净利微薄/盈利弱 | 盈余留存子公司（未分配利润变动≈净利润可证）+ 产能释放与分红潜力 |
| 资产负债率上升风险 | 无息经营性负债为主 + 区间低 + 优于行业/合并口径 |
| 不确定归因写实 | 加“主要系/结合…判断/以…为准”限定 |
| EBITDA 等无折旧数据 | 按“利润总额+财务费用”列示并在注中说明口径 |

### 4. 指标表
```bash
python scripts/indicator_table.py \
  --json audit2023.json audit2024.json audit2025.json audit2606.json \
  --period-label 2026年6月 --last-half --out 本部财务指标分析表.xlsx
```
口径速记：周转与 ROE 用期初期末平均、半年×2 年化标 `*`；利息保障=(利润总额+财务费用)/财务费用、**半年期不列**；现金比率含交易性金融资产；短期债务=短借+应付票据；EBITDA 见话术对照；增长率与资本积累率为百分比值；行业均值取自贵行模板。**生成后人工抽验 3~5 个比率**（尤其负基数变化率符号）。

### 5. 排版输出 docx
用 `scripts/analysis_docx.py` 模板把正文填进去（标题黑体16/一级黑体14/正文仿宋12/首行缩进/表格 Table Grid），保存为《XX财务分析.docx》。若最终要并入主报告，先确认主报告当前使用的简表口径与本文一致（见反幻觉第 3 条）。

### 6. 反幻觉互查（用户要求“与别的版本比对/谁优谁劣”时）
- 按 `scripts/anti_hallucination.md` 清单，把对方每个可疑数字与源证据对质；
- 重点查：应付类科目整行错位、预收/票据跨年语义、EBITDA 折旧虚构、无源具体化（债转股工具/基地注资去向/授信额度）、比率口径前后不一致；
- 输出核查报告 md：结论先行 → 对方问题表 → 我方自检表（含“残留待人工确认”）→ 替换建议；数值替换留痕不静默。

## 校验清单（交付前）
- [ ] 正文每个数字与 JSON 复算一致（可运行 build 的 verify 脚本）；
- [ ] >±30% 变动的科目均已展开（可用脚本从变化率列筛出并核对是否有正文段落）；
- [ ] 负面话术已按对照表软化；
- [ ] 指标表口径注齐全、无虚构折旧/坏账/前五；
- [ ] 反幻觉报告已生成（若要求互查）；
- [ ] 文件可正常打开、表格无错位（docx 用 Word/LibreOffice 打开验证一次）。

## 已知局限
- 数据来源若同时存在合并/本部两套口径，务必在标题与正文标注口径，避免混用；
- “账龄/客户集中度/受限资金/授信合作”等信息须来自附注或行内资料，源文件没有时列为人工核验项。
