# Skill: build-financial-summary-xlsx

把多年 `auditYYYY.json`（见 extract-financial-statements）汇总为银行授信底稿「**近三年及近期财务数据简表.xlsx**」——与行内既有范例**完全同构**（样式 1:1 克隆或按样式快照重建），数值与变化率遵循范例约定。

## 触发场景
- 用户给出多年三表 JSON 或源报表，要求"按范例做一份 XXXX 财务数据简表.xlsx"、"与合并/本部范例完全等同"；
- 已存在一份范例简表（xlsx 或仅 CSV）需要复刻其结构/样式，或以某年度为近一期补充列。

## 前置
- `pip install openpyxl`；脚本与 `row_defs.py` 放在同一目录或加入 `PYTHONPATH`。

## 步骤

### 1. 获取/确认范例
- 优先找行内已定稿的范例 xlsx（如"合并财务数据简表.xlsx"）：有则用**克隆模式**（样式零风险）；
- 若范例已被另存为 CSV（实战常见，会丢样式）：先 dump 样式快照（openpyxl 读 row_dimensions/column_dimensions/number_format/alignment），按 `row_defs.py` 内样式常量核对后走**重建模式**；
- 同时 dump 范例**数值约定**：金额格式（#,##0.00 vs General 的分界）、变化率格式（0.00%）、零值显示（'-'）、表头近一期列写法（文本“2026年6月”/日期序号）。

### 2. 准备映射（一般不需要改）
`row_defs.py` 内置标准 51 行（序号 1..20 层级）科目映射：类型 bs/is/cf、候选前缀、长期投资聚合行、`帐/账`与`预收款项/合同负债`等别名。**仅当贵行模板 B 列文本不同**时修改 `ROWS` 的 label 列表。

### 3. 生成
```bash
python build_summary_xlsx.py \
  --source 2023=audit2023.json --source 2024=audit2024.json \
  --source 2025=audit2025.json --source 2606=audit2606.json \
  --out 本部财务数据简表.xlsx \
  [--template 合并财务数据简表.xlsx]          # 缺省=重建模式
```
- 源 JSON 的 `bs.current` 为期末/本期；期初/上期暂不直接入表（用于连续性校验）。
- 变化率 = **(后 − 前) / |前|**，round 4，格式 `0.00%`；用**两位万元显示值**计算（防 OCR 分币噪声）；前 0/缺且后有值 → ±1，双缺 → '-'.

### 4. 复核（交付前必做）
```bash
python verify_summary_xlsx.py --xlsx 本部财务数据简表.xlsx \
  --json audit2023.json audit2024.json audit2025.json audit2606.json
# 目标输出: 复核差异: 0
```
- 复核含每个金额格（'-' 语义：0/缺失）与每个变化率格；
- 若范例是"跨年右移错版"（他人做的），先与源 JSON 差分定位（见 write-credit-financial-analysis 的反幻觉流程），**不要克隆错误数值**。

### 5. 样式/结构终检
- 行数=54（标题2 + 表头1 + 数据51）、列 A..H；
- 零公式错误（本表为静态值，无公式）；
- 与范例并排抽看 3~5 行：字体、行高、居中/换行、千分位一致。

## 约定速查（默认已在脚本实现）
| 项目 | 值 |
| --- | --- |
| 标题 | 近三年及近期财务数据简表（仿宋14加粗居中） |
| 表头 | 序号｜项目｜2023年｜2024年｜变化率｜2025年｜变化率｜近一期（仿宋10加粗） |
| 单位行 | 单位：万元（居右/居中随范例） |
| 金额格式 | round(元/1e4,2)；\|\|x\|\|≥1000 → #,##0.00，否则 General |
| 零/缺失 | '-' |
| 变化率 | (后−前)/\|前\| round4，0.00%；零基按方向 ±1 |

## 已知局限
- 数据列位置 C/D/F/H 与表头年份按 `--source` 顺序固定；若模板列不同需改 `cols`。
- 克隆模式只覆写 C:H 数据区与 H3 表头，模板其它区域（含备注行）原样保留。
