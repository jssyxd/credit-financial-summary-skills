# Skill: write-micro-credit-report (小微客户一般授信业务调查报告全自动撰写套件)

专门用于银行普惠金融/小微业务条线的**「小微客户一般授信业务调查报告」**全自动编制。
严格遵循银行《小微客户一般授信业务调查报告模板》（如附件7标准体例），涵盖从**客户基本情况、实际控制人资产负债、关联企业、征信涉诉、经营历史、行业与供应链、三年一期财务数据简表与指标计算、销售收入交叉核验、对外担保、银监会流动资金需求量测算，到调查结论与授信方案建议**的全流程。

---

## 业务品种明确区隔与定位

在银行信贷与风控体系中，不同业务品种有严格的边界，本 skill 专门服务于**小微企业一般授信业务**：

| 授信业务品种 | 核心特征与适用主体 | 是否由本 Skill 处理 | 对应的专业处理方式 |
| :--- | :--- | :---: | :--- |
| **小微客户一般授信业务**<br>*(本 Skill 专属范围)* | • 金额通常在 **1000万以内**（普惠口径，部分可拓展至2000-3000万小企业）<br>• 授信主体为小微企业法人或实际控制人个人<br>• 品种：小企业流动资金贷款、无还本续贷、房产抵押借款、科技信用贷等<br>• 报告体例：《小微客户一般授信业务调查报告》标准 8 个核心章节与 11 张表格 | **【是】优先使用本 Skill** | **运行 write-micro-credit-report** 全套工作流与自动化脚本生成 |
| **大中型企业对公授信业务** | • 金额数千万至数十亿元，银团贷款、重资产项目贷款、并购贷款等<br>• 涉及复杂的集团合并报表多口径抵消、行业穿透评级与项目可行性评估 | **【否】非本 Skill** | 采用综合对公调查报告体例，调用 `extract-financial-statements` 提取报表 + `build-financial-summary-xlsx` 制作标准底稿 |
| **专项财务分析切片** | • 仅需要对某企业的三年一期财务做深度科目穿透、话术软化与指标分析 | **【否】（部分协同）** | 调用专门的 `write-credit-financial-analysis` 生成财务分析章节并入主报告 |
| **供应链金融/票据专营** | • 应收账款保理、供应链反向保理、电子商业汇票买断等贸易金融业务 | **【否】非本 Skill** | 需遵循供应链贸易真实性与特定资金池监管规范 |

## 报告标准架构与 11 张表格体系

报告必须严格对应银行小微一般授信标准体例，包含以下 8 大核心章节与 11 张嵌入式表格：

1. **一、授信申请人基本情况**
   - （一）基本情况：对应 **【Table 0: 申请人基本情况表】**（申请人、用款企业、申报金额1000万、注册地址、实收资本、统一社会信用代码等）；
   - （二）实际控制人情况：对应 **【Table 1: 实际控制人基本信息表】**（姓名、台胞证/身份证、常住地址、配偶信息、家庭资产负债与净资产、征信无不良）；
   - （三）法定代表人情况：对应 **【Table 2: 法定代表人基本信息表】**（法定代表人若为实控人则简写或明确同一）；
   - （四）关联企业情况：对应 **【Table 3: 关联企业情况表】**（全资子公司、外贸平台、生产基地等股权穿透与业务协同）；
   - （五）信用状况调查及评价：人行企业信用报告（25年信贷记录、五级分类正常）、裁判文书网、执行信息网、反洗钱筛查，对应 **【Table 4: 案件纠纷及司法核查表】**；
   - （六）其他情况（历史沿革、工商变更、总部搬迁等）。
2. **二、经营情况**
   - 对应 **【Table 5: 经营情况综合分析表】**：公司创立背景与高管履历、主导产品与无水印染等核心工艺突破、行业概况与双碳新质生产力、上下游供应链与核心客户（Adidas、Target等）、竞争格局与护城河。
3. **三、财务情况**
   - （一）主要财务数据：对应 **【Table 6: 近三年及近期财务数据简表、财务指标分析表与流动资金需求测算表】**（51行标准指标、资产负债率、流动比率、周转天数、营运资金量测算及财务综合评价）；
   - （二）销售收入确认情况：对应 **【Table 7: 销售收入交叉核查表】**（银行流水周期与回笼金额、纳税申报表营业收入比对、承兑汇票及收入确认结论）。
4. **四、担保情况**
   - （一）保证人情况（信用借款或实控人连带责任保证）；
   - （二）抵（质）押情况。
5. **五、与金融机构合作情况**
   - （一）已合作金融机构及授信情况：逐笔列示未结清借款（行别、品种、金额、到期日、担保方式），对应 **【Table 8: 授信变动标记说明】**；
   - （二）对外担保情况：对应 **【Table 9: 对外担保明细表】**（核查对外担保余额为0，排除或有负债）。
6. **六、授信用途与流动资金需求测算**
   - 银监会公式量化测算（周转天数、周转次数、营运资金量、缺口覆盖分析）。
7. **七、还款来源分析**
   - 第一还款来源（主营业务收入与品牌订单回款）；
   - 第二还款来源（银行信贷储备与顶级创投股东股权资本支持）；
   - 第三还款来源（知识产权核心资产与实控人信用兜底）。
8. **八、调查结论**
   - 对应 **【Table 10: 经营机构调查结论与建议审批方案】**（申报1000万信用贷、期限不超过1年、优惠利率、还款方式与监管要求）。

## 核心反幻觉原则与防错红线（来自实战审查批注）

依据行内资深信贷审查人员（如钟志斌老师等）在实战报告中的真实批注，AI 在生成小微授信报告时必须严守以下**四大反幻觉铁律**：

1. **绝对禁止模板历史数据残留**：
   - 严禁将参考模板中的企业名称（如聚时科技）、人名（如郑军、赵丽媛）、借款事件（如“浦发银行节假日延期导致的关注类借款”）复制到新报告中！
   - 每一户企业的征信状况必须以当期人行信用报告为准。
2. **报表数据必须三源一致**：
   - 审计年报数据、电子税务局纳税申报表（A100000表）与正文叙述必须完全吻合，变动率必须与简表完全一致。
3. **缺失材料一律“留空待补充”，严禁编造**：
   - 企业未提供的实控人家庭房产明细、配偶证件、员工花名册、特定历史年度数据等，一律规范标注**“留空待企业提供资料补充”**，绝不进行虚假编撰。
4. **每一段核心事实均需注明【事实依据与来源】**：
   - 工商信息注明公示系统；征信数据注明信用报告编号与页码；客户合作注明BP或公开采购签约；财务数据注明纳税申报表行次。

## 自动化工具与执行脚本

本 skill 配套提供了经过生产验证的自动化辅助脚本（位于 `skills/write-micro-credit-report/scripts/`）：

1. `calculate_working_capital.py`：
   - 自动按照银监会《流动资金贷款管理暂行办法》标准公式计算营运资金周转天数、周转次数、营运资金需求量及缺口覆盖额。
2. `verify_report_evidence.py`：
   - 自动扫描生成的 docx/文本报告，全面排查模板历史数据残留、征信矛盾、数据不一致及未标注溯源缺陷。
