# 端到端工作流（WORKFLOW）

从“三年一期源文档”到“简表 + 分析 + 指标表”的标准做法。本文是给执行 Agent 的分步清单，配合各 Skill 的 SKILL.md 使用。

## 0. 识别任务
- 确定口径：**合并**（集团）或 **本部（母公司单体）**；同一项目常两套都要（分别建目录）；
- 确定“三年一期”：近三年审计报告（2023/2024/2025 年报）+ 近一期报表（如 2026-6 简式/半年度）；
- 找范例：行内已定稿的同口径简表 xlsx（克隆样式 + 校验约定）或 CSV（仅数据）；
- 找对照：是否已有“别人做的”版本（其他 AI/同事）→ 纳入反幻觉互查。

## 1. 输入分类与预转
```
任何doc → 文本层? → 是: pdf_rowdump 坐标重建(双栏必用)
                 → 否: OCR 管线(ocr_page/ocr_crop)
```
- 文本层全量先 anydoc 预转 _md/（Agent 判读快）；
- 扫描件才进 OCR；文本层那份不要浪费 pane。

## 2. 提取（extract-financial-statements）
- 定位报表页 → 三表全行 → `auditYYYY.json`；
- 自校验恒等式；跨年跑 validate_extraction.py；
- 附注按需（notesYYYY.json）——判披露粒度，供分析与反幻觉使用。

## 3. 建表（build-financial-summary-xlsx）
- 有范例 → 克隆模式；无 → 重建模式（样式快照）；
- 数值/变化率约定见 README 6.3/6.4；
- 复核 306 格 0 差异；与“别人版本”做全表差分（若存在）。

## 4. 写作与指标（write-credit-financial-analysis）
- 正文结构见 SKILL；±30% 科目必展开；话术软化表套用；
- 指标表 indicator_table.py；附注极简时 EBITDA 走 EBIT 口径并加注；
- docx 排版输出；若并入主报告，先替换主报告内嵌的错误简表。

## 5. 互查与交付
- 反幻觉核查（anti_hallucination.md）生成报告 md；
- 交付清单：简表 xlsx、分析 docx、指标表 xlsx、核查报告 md；
- 主报告内嵌表格/数字同步更新（若适用）。

## 命名约定（项目目录）
```
<root>/
  合并三年一期报告/ 或 本部三年一期报告/      # 源 PDF
  <口径>财务数据简表.xlsx                     # 交付1
  <口径>财务分析.docx                         # 交付2
  <口径>财务指标分析表.xlsx                   # 交付3
  反幻觉核查-<口径>财务分析.md                # 交付4(可选)
  <口径>三年一期报告/_extract/                # 中间产物(可整目录清理)
```
