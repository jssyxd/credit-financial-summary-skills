# 术语与口径（TERMINOLOGY）

## 主体口径
| 词 | 含义 | 典型来源 |
| --- | --- | --- |
| 合并（合并报表） | 集团并表口径：母+所有子公司，内部往来/交易抵销 | 合并审计报告 / 合并 XX2606 |
| 本部 / 母公司单体 | 仅上海母公司自身口径；对子公司投资=长期股权投资；内部往来保留在资产负债上 | 单体审计报告 / 本部 XX2606 |
| 三年一期 | 近三年年报（2023-12-31、2024-12-31、2025-12-31）+ 近一期报表（如 2026-06-30，利润/现金流为 1-6 月累计） | — |

## 报表体例
| 词 | 特征 |
| --- | --- |
| 新准则审计报表（审计报告） | 科目较全；应收/应付票据、应收账款等单列；通常附注披露；可能含期初(=上年末) |
| 银行简式会企表（近一期常用） | 双栏行次制（资产左/负债权益右，行次 1..61），金额列=期末余额/年初余额，文本层多；期初=上年审计末（**文本锚点**） |
| 极简附注 | 各科目仅“期末/期初”单行合计，无分类明细、无折旧拆分、无账龄分段/坏账/前五名 |

## 科目别名（简表行 ↔ 报表科目）
- 应收帐款=应收账款；应付帐款=应付账款（账/帐 混用）
- 预付账款=预付款项；预收账款=预收款项/合同负债（按源表实际列示取数，简表行可能聚合）
- 实收资本=实收资本（或股本）/股本
- 所有者权益合计=所有者权益（或股东权益）合计（注意半/全角括号）
- 长期投资（简表聚合行）=长期股权投资+可供出售金融资产+持有至到期投资+债权投资+其他债权投资+其他权益工具投资+其他非流动金融资产+长期应收款
- 其他应付款：审计口径常含“应付利息”并入；简式表把应付利息单列 → 跨口径比较时注意
- 货币资金：期末值应=现金流量表“期末现金及现金等价物余额”（受限资金另披露时不等，作为受限检测）

## 数值约定
- 元 → 万元：÷1e4 后 round 2；
- 零/报表无此科目 → 简表显示 `-`；
- 千分位：#,##0.00（|x|≥1000 的范例惯例），小值 General；
- 变化率：(后−前)/|前| round4，0.00% 格式；负基数按变动方向定号。

## 校验词
- 配平：资产=负债+权益；IS/CF 链式恒等（允许 ≤0.5 元差）；
- 连续性：后年期初 = 上年期末（命名/口径差异需解释）；
- 文本锚点：近一期简式表“年初余额”= 上一审计年末（数字必须相等）。
